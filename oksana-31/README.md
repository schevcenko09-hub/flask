# Оксана — 31 год великолепия ✨

Премиальный поздравительный сайт для GitHub Pages. Использует HTML, CSS, JavaScript, Bootstrap 5 и `.container`.

## Запуск локально
Открой `index.html` в браузере. Для локального тестирования можно использовать расширение Live Server в VS Code.

## Публикация на GitHub Pages
1. Создай публичный репозиторий, например `oksana-31`.
2. Загрузи `index.html`, `style.css`, `script.js`, папку `images` и, если используешь музыку, `music.mp3`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
6. Подожди пару минут. Ссылка появится в разделе Pages и будет выглядеть как `https://ТВОЙ-ЛОГИН.github.io/oksana-31/`.

## Как заменить фотографии
Положи фотографии в папку `images` и замени `images/oksana-1.png` и `images/oksana-2.png` на свои файлы. Если меняешь имена файлов, обнови `src` и `data-full` в `index.html`.

## Как добавить музыку
Положи MP3-файл рядом с `index.html` и назови его `music.mp3`. Музыка включается только после нажатия кнопки посетителем — браузеры обычно блокируют автозапуск звука.

## Важно
Bootstrap и шрифты загружаются с CDN, поэтому для их загрузки нужно подключение к интернету. Не добавляй личные фотографии в публичный репозиторий, если не хочешь, чтобы их могли увидеть другие люди.
